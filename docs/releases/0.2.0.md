The biggest release since the first one: Python notebooks that talk to the canvas, an AI that directs your videos, a desktop app, and downloads for every system.

## Download

| You want | Get |
| --- | --- |
| **An app, no setup** | the installer or portable file for **Windows**, **Linux** (AppImage, deb, rpm, tar.gz) or **macOS** below |
| **Docker** | `docker run -p 127.0.0.1:3000:80 ghcr.io/balalex12/trazo:VERSION`, or the compose file in the repository |
| **Serve it yourself** | `Trazo-Web-VERSION.zip`: static files and a small launcher (Node.js 18+) |
| **Python notebooks in the desktop app** | `Trazo-Notebook-Pack-VERSION.zip` (a few hundred MB), see docs/DESKTOP.md |
| **Check what you downloaded** | `SHA256SUMS` |

The installers are **not signed**: Windows and macOS will warn the first time (docs/DESKTOP.md says what to click). The published builds use the **public icon library**: without the Esri Calcite glyphs (whose redistribution is not settled) and without libraries that carry third-party brand logos; build it yourself from the repository for the full library.

## What is new since v0.1.0

**Notebooks, inside Trazo.** A Python notebook panel (Pyodide, in the browser, offline) next to the canvas: a live diagram of the data flow that lights up while a cell runs and shows table sizes, a `trazo` Python module to read the canvas and draw on it, `trazo.map` for a hand-drawn map from a GeoDataFrame, a notebook drafted from a diagram, **compare the diagram with the notebook** (planned but not coded in red, coded but not drawn in orange), and **slides from the notebook** for the Animation panel. You can also run the Python in **your own Jupyter server**, with its packages. Jupyter notebooks import as a data-flow diagram too.

**Your own AI, as director and composer.** _Direct with AI_ writes captions, narration scripts, hold times and transitions for your slides; _Compose with AI_ writes a motion graphic; a **local voice** (Kokoro) narrates it; the HTML player export is also a HyperFrames composition. From a notebook to a narrated MP4 in one chain, documented step by step. Everything is off until you connect a model (Ollama, LM Studio, Ollama Cloud, any OpenAI-compatible server or Anthropic).

**The Agent panel draws.** Describe a diagram and it is laid out by Trazo, with the same engine as the imports. The MCP server shares the same code.

**Import to diagram.** docker-compose, Kubernetes, Terraform, OpenAPI, SQL (schemas and queries), dbt, n8n, Jupyter notebooks and any JSON, with elbow arrows.

**Animation and recording.** Build and pan transitions, captions, more easings, narration recorded per slide and mixed into the MP4, a recorder with microphone, maps and whole-app modes.

**Libraries.** Own icon packs for GIS, data engineering and machine learning (original, MIT). The font fallback is now **Arimo (OFL)**, which closes the per-font license audit.

**Quality.** A browser test suite in a real Chrome (and a manual workflow for the notebook tests), retries for a few timing-sensitive inherited tests, and a CI that checks the Docker image builds.

## Status and known limits

- Verified with automated tests and by hand. If something does not work on your system, please open an issue.
- Still unvalidated: the Utility Network trace with a real Web Map, and the AI connector against LM Studio, OpenAI and Anthropic.
- Screen recording of the whole app is not available in the desktop app yet.
- Interactive map embeds appear as a placeholder in exported video.
