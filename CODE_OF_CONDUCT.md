# Code of Conduct

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive; no harassment, discrimination or personal attacks; assume good faith; give
credit; keep discussion on topic. Maintainers may remove comments, commits or contributors that violate this.

Report problems privately to the maintainers through GitHub (repository → *Security* → *Report a vulnerability* for
sensitive matters, or a direct message to a maintainer). All reports are handled confidentially.
